# Офис Максима

Рабочее пространство Максима Лунева: Heliclub (клиенты, хранение, полёты, обслуживание, счета, вертолёты, сделки Bell) и стройка (флип-хаусы).

- Next.js 15, Postgres (Neon), Claude API с кэшированием промптов.
- Вход по паролю, который Максим задаёт при первом открытии.
- Коннектор для Claude: `/api/mcp/<секрет>` — адрес показывается в приложении («Ещё»).
- Расписание (vercel.json): утренняя сводка 05:30 UTC, черновики счетов 1-го числа.

## Переменные окружения
- `DATABASE_URL` — Neon (Vercel → Storage → Neon).
- `ANTHROPIC_API_KEY` — ключ Claude API (можно вставить и в приложении).
- `CRON_SECRET` — защищает расписание.
- `WINDY_KEY` — по желанию: ветер и облачность по Windy (без него — Open-Meteo).
- `WHOOP_CLIENT_ID`, `WHOOP_CLIENT_SECRET` — по желанию, приложение на developer.whoop.com с адресом возврата `https://<домен>/api/whoop/callback`.
